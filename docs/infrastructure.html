Infrastructure

Built independently.
Designed to stay replaceable.

Norfold uses third-party providers for hosting, storage, and delivery. Provider independence is an architectural goal — the design should not trap the product in a single provider.

Architecture

The provider boundary.

The Norfold contract sits above the provider layer. Providers are replaceable implementations — not permanent architectural dependencies.

Norfold contract

1
Privacy modelE2EE, security modes, deletion, and relay behavior are defined at this layer.

Provider adapterThe interface between Norfold's contract and the current provider implementation.
