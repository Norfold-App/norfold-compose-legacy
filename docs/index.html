Local-first

Local first. Network second.

Work continues without a network. Changes queue locally. When the network returns, state reconciles — without losing what happened offline.

Security

Two security modes. Zero silent downgrades.

Personal DMs and groups are designed around end-to-end encryption. Workspaces may use E2EE or Managed mode — and members should see which mode they are in.

Data lifecycle

Messages move.
Ownership stays clear.

A secure messaging system is more than an encryption label. Norfold separates the live cryptographic session, temporary relay, local history, private archive, and destructive-state rules.

Explore data & recovery →
01 / CREATE

Your device creates the content.

Private message content is encrypted on an authorized device before normal E2EE relay. Local-first UI does not wait for a round-trip merely to display what you just sent.

02 / RELAY

The server moves what it does not need to understand.

Temporary ciphertext delivery, membership routing, push events and operational metadata remain different from keeping a permanent readable private message archive.

03 / KEEP

Your devices and archive hold long-term history.

The archive provider is a replaceable implementation. A future self-hosted provider should not force Norfold to redesign its privacy model.

04 / REMOVE

Deletion and lifespan stop ordinary resurrection.

Delete-for-everyone and explicitly destructive lifespans should block normal relay, recovery-relay, and routine archive restoration paths after destruction.
