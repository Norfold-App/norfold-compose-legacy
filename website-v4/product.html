Product

One workspace.
Different ways to think.

Write freely. Structure when needed. Turn work into action. Keep the conversation beside the work — without making the cloud a requirement.

Notes

Capture first. Structure later.

The fastest path from thought to record. Flowing text, quick structure, links to tasks and data. Notes stay connected to the work they inform.

✦

Flowing text

Write without friction. Notes accept free-form content and gain structure only when you choose to add it.

IMPLEMENTED
⬡

Connected to work

Notes link to tasks, documents, and conversations. The relationship is preserved, not just the text.

IMPLEMENTED
Documents

Structured pages when you need them.

Bounded pages, structured blocks, typography, and image placement. Documents are for work that needs a defined shape. Major editor redesign is currently in progress.

▣

Structured blocks

Native block system shared by notes, task documents, and calendar-event documents. One surface language across the workspace.

IN PROGRESS
◫

Publishing surface

Typography, image placement, and structured layout for work that needs to be shared or presented.

IN PROGRESS
Editor redesign in progress

The document editor is undergoing a major architectural redesign. Current capabilities are partial. Do not rely on editor stability before public release.

Tasks

Work that needs to get done.

Properties, checklists, files, comments, date ranges, and custom statuses. Move the same task data through the view that fits the work.

◎

Multiple views

List, board, calendar, and timeline. The same task data adapts to the view without duplication.

IMPLEMENTED
◈

Rich task properties

Custom statuses, date ranges, checklists, file attachments, and comments. Tasks carry the context they need.

IMPLEMENTED
Chat

Conversation beside the work.

Encrypted account messaging. Stage 1 backend deployed and under validation. Not yet release-certified.

◈

Personal E2EE messaging

Direct messages and personal groups are designed around end-to-end encryption. The server moves what it does not need to understand.

VALIDATING
⊞

Workspace chat

Channels and group conversations within a workspace. Security mode follows the workspace's owner-selected setting.

VALIDATING
Chat validation status

Stage 1 chat backend is deployed. Adversarial, multi-device, and load validation are ongoing. Chat is available for testing but not certified for production use.

Shared work

Local-first by default. Shared when you choose.

Collaborator trace, selected objects, comments, and workspace boundaries. Your workspace stays on your device unless you explicitly configure sharing.

⬡

Workspace collaboration

Shared workspaces with explicit membership, roles, and security modes. Collaboration does not require surrendering local-first behavior.
