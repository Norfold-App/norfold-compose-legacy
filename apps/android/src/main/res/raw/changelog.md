Norfold 0.1.0-alpha.3

EDITORS

• Docs, Flow and Spreadsheet are one editor now: three hosts over the same document model, so a table, chart, image or diagram behaves the same wherever you meet it.
• Added Chart Studio, Image Focus, Shape Builder, the equation builder and the diagram builder.
• Selecting an object shows one frame with one inspector, keyed on what the object is.
• Slash commands, a command rail, named styles, and bundled fonts that do not need a network.
• History browser, named snapshots and a recovery browser, held on the device.

TASKS

• Table, Board, Feed, Calendar, Chart, List, Timeline and Matrix views, with manual order preserved.
• Task properties have a management surface again: add, rename, reorder and remove them.
• Task reminders now fire. Earlier builds stored them and never delivered them.

CHAT

• Encrypted messages, media and archives; personal groups, workspace channels, and message requests.
• Disappearing messages, privacy-safe abuse reporting, and per-conversation mute.

NOTIFICATIONS

• A new Notifications section in Settings covers task reminders and quiet hours. In-app tips and email delivery remain unavailable in this build, so those saved preferences do not change behaviour yet.
• Quiet hours hold a reminder until the window ends rather than dropping it. A message somebody sent always arrives; the most any preference does is take away its sound.

ACCESSIBILITY

• Every focusable control the keyboard can reach now shows a focus ring.
• Screen readers announce a setting's name, role and state as one thing, and long-press actions are discoverable.
• Secondary text meets AA contrast on both canvases, and directional icons mirror in right-to-left layouts.

WORKSPACE

• Onboarding is a resumable ten-step local-first flow.
• Workspace, Permissions, Backup, Import, Sync and Conflict settings are consolidated, and workspace deletion sits under its own Danger zone.
• Encrypted backup and local diagnostics.

ABOUT THIS BUILD

This is an alpha. It is not release-signed, and it has not been certified on a physical device — real-device keyboards, gestures and notification delivery still need validation. Keep your own copy of anything you cannot afford to lose, and export a backup before testing import, export, sync or the vault.

Cloud controls appear only when their public configuration is present. Live collaboration is off in this build because there is no backend deployed for it to reach; local history and merging do not depend on it.
